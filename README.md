# 手游情报站

下载新手游不知道刷什么？输入游戏名，AI 帮你搜 B站和 Wiki，直接给你：新手路线、每天刷什么、角色 Tier List。

## 用法

下载 `index.html`，浏览器打开，填入 Claude 或 OpenAI 的 API Key 就能用。

没有 Key 的话去这里注册：
- Claude：[console.anthropic.com](https://console.anthropic.com)（推荐，便宜一点）
- OpenAI：[platform.openai.com](https://platform.openai.com)

Key 只在你本地浏览器里跑，不经过任何服务器。

## 部署

推到 GitHub 之后开 Pages 就行，Settings → Pages → Source 选 main，等一分钟就有公开链接了。
